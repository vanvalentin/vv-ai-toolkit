# Platforms

Reusable reference architectures and sanitized configuration patterns for running AI workflows outside a single editor.

## Available

- [Pi Discord Specialists](pi-discord-specialists/README.md) — a private, self-hosted Discord interface in which each specialist channel creates persistent, isolated Pi conversations with least-privilege tools, shared specialist memory, model fallback, and scheduled work.

Platform folders are blueprints, not exports of a live installation. They deliberately omit credentials, account identifiers, private hostnames, network details, user data, logs, browser profiles, and production state.
