# Job offer evaluation

Follow the canonical workflow in:

- `offer-intelligence/methodology.md`
- `.agents/skills/job-offer-evaluation/SKILL.md`

Read both before a full evaluation. Use the project `offer-intel` MCP server for public
research when it is available, but continue with clearly labeled, user-provided
evidence when it is not.

Keep factual claims adjacent to citations. Separate posting claims, user-provided
facts, inferences, and unverified claims. State source limitations, blocked pages,
assumptions, and confidence. Never promise live access to Glassdoor or any other site.
Do not log in, bypass access controls, expose credentials, or request personal data
that is unnecessary for the decision.
