# Interview preparation

Follow the canonical workflow in:

- `interview-prep/methodology.md`
- `.agents/skills/interview-prep/SKILL.md`

Read both before a full prep pack or graded mock. Use the project `offer-intel` MCP
server for public employer and interview-process research when it is available, but
continue from the CV and JD when it is not.

Keep factual claims adjacent to citations. Separate posting claims, user-provided
facts, inferences, and unverified claims. Never invent experience or metrics. Never
promise live access to Glassdoor or any other site. Do not log in, bypass access
controls, expose credentials, or request personal data that is unnecessary for prep.
